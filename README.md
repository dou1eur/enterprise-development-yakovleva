# Car Rental Service - Сервис проката автомобилей

## Предметная область

Система управления пунктом проката автомобилей, содержащая информацию о парке транспортных средств, клиентах и операциях аренды.

## Описание бизнес-процессов

### Управление автопарком
- **Автомобиль** характеризуется поколением модели, госномером, цветом
- **Поколение модели** является справочником и содержит сведения о годе выпуска, объеме двигателя, типе коробки передач, модели
- **Модель** является справочником и содержит сведения о названии модели, типе привода, числе посадочных мест, типе кузова, классе автомобиля

### Управление клиентами
- **Клиент** характеризуется номером водительского удостоверения, ФИО, датой рождения

### Процесс аренды
- При выдаче автомобиля клиенту фиксируется время выдачи и указывается время аренды в часах
- Каждая аренда используется в качестве контракта

## Юнит-тесты

1. **Вывести информацию обо всех клиентах**, которые брали в аренду автомобили указанной модели, упорядочить по ФИО
2. **Вывести информацию об автомобилях**, находящихся в аренде
3. **Вывести топ 5 наиболее часто арендуемых автомобилей**
4. **Для каждого автомобиля вывести число аренд**
5. **Вывести топ 5 клиентов по сумме аренды**


### VehicleModel — это справочник автомобильных моделей с общими характеристиками. Каждая модель может выпускаться в нескольких поколениях с различными техническими характеристиками

**Свойства:**
- Название модели
- Тип привода (DriveType)
- Количество посадочных мест
- Тип кузова (BodyType)
- Класс автомобиля (VehicleClass)


### VehicleGeneration — расширяет модель конкретными техническими характеристиками и тарифами. Одно поколение может включать множество физических автомобилей с идентичными характеристиками

**Свойства:**
- Год выпуска поколения
- Объем двигателя
- Тип коробки передач (Transmission)
- Стоимость аренды в час


### Vehicle —— авто в автопарке. Один авто можно арендовать множество раз

**Свойства:**
- Регистрационный номер
- Цвет авто
- Привязка к поколению модели

### Renter — информация о клиентах проката. Связан с Rental, так как один арендатор может пользоваться услугами аренды множество раз

**Свойства:**
- Номер водительского удостоверения
- Полное ФИО
- Дата рождения

**Связи:**
- Участвует в отношении **"один ко многим"** с `Rental`
- Один арендатор может совершить множество аренд

### Rental — объединяет автомобиль и арендатора, фиксируя факт аренды

**Свойства:**
- Время начала аренды
- Продолжительность в часах
- Автоматический расчет стоимости

### BodyType
Определяет типы кузовов:
- Седан
- Хэтчбек  
- Внедорожник
- Купе
- Кабриолет
- Минивэн
- Пикап

### DriveType
Классифицирует типы привода:
- Передний привод (FWD)
- Задний привод (RWD)
- Полный привод (FourWD)
- Полный привод (AWD)

### Transmission
Охватывает все типы трансмиссий:
- Механическая КПП
- Автоматическая КПП
- Вариатор (CVT)
- Роботизированная КПП (AMT)
- Преселективная КПП (DCT)

### VehicleClass
Категоризирует автомобили по классам:
- Мини
- Эконом
- Компакт
- Семейный
- Бизнес
- Люкс
- Внедорожник
- Минивэн
- Кабриолет
- Спортивный
